# 文献综述六步法

## 方法与输入

把文献综述写成围绕问题与假说展开的论证。先归纳，再分类比较、评价和检验论证，最后提出改善已有认识的猜想。不要把逐篇摘要拼接成综述。

开始前读取 [方法依据](references/method.md) 和 [输出模板](references/output-templates.md)。本技能根据第四讲转述整理；六步名称、顺序来自原书，其余字段、证据标记和执行约束是为 agent 增加的操作要求。

明确研究主题、研究对象、研究问题、综述范围、已有文献、目标篇幅和引用规范。优先利用用户已有材料；只询问无法推断且影响研究边界的信息。没有明确问题时，先从文献提出候选问题并标记待确定，继续阅读比较，避免提前锁定结论。

正式写作前建立文献清单及选择理由。原书建议搜集不少于 30 篇相关文献、辨认最相关的 1—3 篇，并兼顾重要文献与近期英文文献。将这一数量视为覆盖目标：用户限定材料、练习任务或材料不足时照常推进，报告覆盖边界与待补项，不凑数量、不宣称穷尽。

核实文献题名、作者、年份、出处和 DOI/链接。用全文中的具体内容支撑比较；只有摘要时明确标记“仅摘要”，不得据此杜撰模型、变量或识别细节。原文未报告时填写“未报告”；未取得材料时填写“待核实”。检索最新文献时使用当时可用的检索工具并记录检索日期与范围。

## 强制输出契约

执行本技能的 agent 必须按顺序交付下列六步成果。即使用户只要求最终正文，也将中间成果放入同一交付文件的附录或独立附件，并提供可访问入口。不要仅声称“已完成六步”，不要只返回最终综述。输出可核查的研究成果、理由和证据，不输出内部思维过程。

用户明确只做某一步时，仅完成该步并标明其他步骤未执行。重写已有综述时可复用经核实的旧成果，但仍列明其来源与更新状态。篇幅较大时在文件中交付完整卡片、表格和图，不用省略号代替内容。

由主 agent 按依赖关系推进六步；不要默认六步彼此独立。用户要求多 agent 时可并行分派文献阅读，统一卡片字段、文献 ID 和证据格式；第三步必须使用第二步结果，后续步骤使用前序成果。汇总后由主 agent 负责来源核查与最终一致性。

## 第一步：记笔记与制卡片

逐篇阅读并制卡片。记录研究问题、核心概念、理论与假说、数据及样本、研究思路、变量和指标、方法及识别、结论、局限、与本研究的关系。给文献稳定 ID，保留原文页码/章节/表号；把作者结论与 agent 的评价分开。重点摘出结论性元素和可能影响结论的研究设计元素。

**必须输出：**完整文献清单、每篇文献卡片、选择理由、最相关的 1—3 篇及与本研究的异同、未获取/待核实材料。

## 第二步：打表格

以本研究目标设计比较栏项，将卡片整理成文献比较表。至少比较问题/视角、理论假说、数据、变量、方法、结论。分别按结论和可能导致结论差异的设计因素分类；同一维度内尽量穷尽并相互排斥，不混用数据、方法和观点作为同层类别。不同维度可另建表。

明确可比较标准与边界，避免把不同对象、概念或估计量的结果视为直接冲突。提出两类暂定分析命题：解释已有认识分歧/不足的命题，以及可能改善该不足的命题。二者属于文献分析层面的猜想，须进一步论证，不能当成已证实的经验结论。

**必须输出：**填充后的比较表、分类与比较标准、共识/分歧清单、差异原因的暂定解释及证据。

## 第三步：画文献结构图

围绕研究问题、评价标准或可能创新点，将相关内容分成模块。交代各模块对应哪些文献、回答什么问题、与其他模块如何连接。结构按分析需要组织，可采用逻辑、时间或空间顺序，不机械按国内/国外划分。

**必须输出：**可渲染的文献结构图（优先 Mermaid）和模块—文献 ID 对照表、模块关系说明。图应展示模块间的实质联系、分歧或论证路径。检查覆盖范围、逻辑层次和与研究目标的关系；无法绘图时提供明确标记的层级结构表，说明格式限制，不声称已绘图。

## 第四步：看图表“说话”

将表与图中的比较结果写成有证据的分析段落，依次回答：已有认识是什么，在哪里分歧或不足，差异可能来自什么，按什么标准评价，哪些证据支持或反驳该解释，怎样改善。评价标准可来自理论推演、明确的理想参照或在指定范围内成立的相对标准；说明适用范围。

针对核心判断组织“论点—比较证据—解释—适用边界”。不得用“某研究发现……”代替对具体问题的论证；不得把研究设计不同直接断言为造成结论不同的因果证据。认真处理反例与替代解释。新假说需有理论基础、可操作的变量/指标，以及文献中的参照或靶子假说；没有足够依据时保留为待检验猜想。

**必须输出：**图表分析段落、论证与证据对应表、分歧原因命题和改善命题的支持/反证/不确定性、候选研究问题与假说及其理论与检验依据。

## 第五步：分门别类

按结构图模块组织小标题，将表格归类内容写成连贯正文。小标题优先表述观点或具体问题。采用“总—分—总”：引入研究目标、问题、分析视角与分节理由；各节说明本节任务并进行比较评述；结尾回答分歧是什么、可能改善的思路是什么，并引出本研究问题和待检验假说。

段落围绕中心观点分点，按需要采用并列、时间顺序或正反写法。让引文支持观点，避免连续按作者或年份点名。不要虚构创新、研究结果或政策意义。

**必须输出：**含引入段、分类评述主体、小结的完整综述初稿及与正文引用一致的参考文献。

## 第六步：检查完善

按“综述全面、论证充分、逻辑清晰”三项标准检查，并检查本讲四个要点：有引入段、有文献结构图、有具体内容比较表、有引出研究问题与假说的结论。检查是否存在罗列复制、偏离问题、缺少假说、分类不合理、没有比较、论证不足六类问题。

核查每项关键断言的来源、引用与页码、卡片—表格—结构图—正文的一致性、重要和近期文献的遗漏、反证、研究缺口是否具体。修正能解决的问题；无法核实的内容降级为不确定或移除。不得把“未见某类研究”写成“从未有人研究”，除非检索证据足以支持。

**必须输出：**检查表（结果、证据、修正）、简明修改记录、尚未解决的材料缺口、修订后的最终正文与参考文献。不得用勾选清单代替实际修改。

## 完成交付

按六步编号组织交付目录，确保每一步都有实际成果。可以将初稿和最终稿分别放在文件中，避免正文重复占用聊天篇幅。最终说明已完成的成果、文献覆盖范围和仍影响结论的限制。将用户需要的成果按当前环境支持的持久化流程保存；遵循用户指定格式。
